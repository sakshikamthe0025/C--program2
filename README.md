# Addition of Two Integers in C

## Description
This is a simple C program that adds two integers and displays the result.

## Algorithm
1. Start.
2. Initialize the first integer `i` to `10` and the second integer `j` to `11`.
3. Add `i` and `j`, and store the result in `k`.
4. Display the value of `k`.
5. Stop.

## Source File
- `program.c` — contains the C program.

## Requirements
- A C compiler, such as GCC.
- A terminal or command prompt.

## How to Compile and Run

Compile the program:

```bash
gcc program.c -o program
```

Run it on Windows:

```bash
program.exe
```

Run it on Linux/macOS:

```bash
./program
```

## Expected Output

```text
21
```

## Concepts Used
- Integer variables
- Addition using the `+` operator
- `printf()` to display output
- `main()` function and `return 0`
